# Annotation Guide

## Tool

LabelImg

## Annotation Format

YOLO

## Label

box

## Procedure

1. Open image
2. Press W
3. Draw rectangle around carton
4. Enter label: box
5. Save

## Examples

Correct:

Bounding box tightly surrounds carton.

Wrong:

Bounding box includes shelf.

Wrong:

Bounding box includes empty area.

## Notes

All cartons use same label.

Do not create:

box-1
box-2
box-3

Use:

box
